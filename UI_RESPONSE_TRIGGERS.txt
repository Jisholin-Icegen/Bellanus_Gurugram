=====================================================================
  UNIFIED AI BRIDGE - API CONTRACT  ("UI Response Triggers")
=====================================================================
You only need TWO calls in normal use:

    1 GET  -> ask the app "what is on the screen right now?"
    2 POST -> tell the app "do this" (the AI response triggers the UI)

(There is also a GET .../results you poll ONLY if you want to confirm
each action succeeded - optional.)

BASE URL
--------
    https://<your-host>/api/ai-bridge

AUTH
----
AI-team endpoints need this header on EVERY request:
    X-Api-Key: <AiBridge:ApiKey from server appsettings.json>

The session_id itself is the device credential - no login needed.

---------------------------------------------------------------------
STEP 1 - GET  (one call: everything the AI needs to decide)
---------------------------------------------------------------------
GET /api/ai-bridge/sessions?bed_id=9330
    -> which device(s) belong to this bed (pick session_id from here)

GET /api/ai-bridge/sessions/{session_id}/options
Headers: X-Api-Key: <key>

Response - this is the FULL payload the AI works from:

{
  "session_id": "9f2c1e8a-....",
  "bed_id": "9330",
  "device_id": "4f84ed4b-81f8-4381-80ac-4da1834ac9bb",
  "call_active": true,
  "route": "/FoodDining/MenuItems",
  "title": "Menu Items",
  "screen_version": 72,
  "headings": ["Today's Menu", "Starters"],
  "options": [
    {
      "id": "nav:/FoodDining/FoodOrdering",
      "type": "navigate",
      "label": "Order Food",
      "action": { "action": "navigate", "path": "/FoodDining/FoodOrdering" }
    },
    {
      "id": "unified-action-abc",
      "type": "click",
      "label": "Paneer Tikka",
      "action": { "action": "ui.click", "targetId": "unified-action-abc", "label": "Paneer Tikka" }
    },
    {
      "id": "select:portion:large",
      "type": "select",
      "label": "Large",
      "group": "Portion",
      "action": { "action": "ui.select", "controlId": "portion", "optionValue": "large" }
    },
    {
      "id": "unified-field-xyz",
      "type": "fill",
      "label": "Special instructions",
      "needs_value": true,
      "action": { "action": "ui.fill", "targetId": "unified-field-xyz", "value": "<patient's words>" }
    }
  ],
  "items": []
}

WHAT EACH FIELD MEANS (what you send the AI / what it reads):
  route/title/headings : where the patient is and what the page says
  options[].label      : the visible button/control text (patient words map to this)
  options[].action     : READY-MADE command - copy it into the POST body as-is
  items[]              : list rows on the page (menu items, orders, notifications)
  call_active          : true while a voice call is live

PARAMETERS YOU CONTROL:
  bed_id        -> which patient's device (from your system / QR)
  session_id    -> which screen/tab (from step "sessions" list)
  include_raw=1 -> (optional) adds the untouched screen JSON

---------------------------------------------------------------------
STEP 2 - POST  (the response that TRIGGERS the application)
---------------------------------------------------------------------
POST /api/ai-bridge/sessions/{session_id}/actions
Headers: X-Api-Key: <key>
         Content-Type: application/json

Body - put the action objects from step 1 inside "actions":

{
  "request_id": "req-123",               // optional tracking id
  "transcript": "I am hungry",           // what the patient said (optional)
  "actions": [
    { "action": "navigate", "path": "/FoodDining/FoodDining" },
    { "action": "ui.click",   "targetId": "unified-action-abc", "label": "Paneer Tikka" },
    { "action": "ui.select",  "controlId": "portion", "optionValue": "large" },
    { "action": "ui.set_choice", "targetId": "unified-choice-1", "checked": true },
    { "action": "ui.fill",    "targetId": "unified-field-xyz", "value": "less spicy" },
    { "action": "food.add_item", "foodId": "123", "meal": "Lunch", "quantity": 1 },
    { "action": "food.submit_order" },
    { "action": "request.create", "module": "room_comfort", "details": "extra pillow" },
    { "action": "notification.mark_all_read" },
    { "action": "feedback.answer" },
    { "action": "video.play" },
    { "action": "video.stop" }
  ],
  "suggestions": [
    { "label": "Order again",
      "action": { "action": "navigate", "path": "/FoodDining/FoodOrdering" } }
  ]
}

RULES:
  - <=10 actions, <=8 suggestions, body <=64 KB per POST.
  - action names allowed: navigate | ui.* | video.* | food.* |
    request.* | notification.* | feedback.*   (anything else -> 400)
  - navigate.path must be a SAME-SITE path like "/FoodDining/FoodDining".
  - ui.* targetId/controlId/optionValue come straight from step 1 options[].
  - ui.fill "value" = the text the patient actually said.
  - suggestions show as tappable chips on the patient's screen.

202 Accepted
{
  "accepted": true,
  "request_id": "req-123",
  "actions": 2,
  "suggestions": 1,
  "delivered_to_streams": 1
}
delivered_to_streams = 0 -> device offline; it replays for ~10 s.

---------------------------------------------------------------------
STEP 3 (OPTIONAL) - GET results = did the device actually do it?
---------------------------------------------------------------------
GET /api/ai-bridge/sessions/{session_id}/results?after=0
Headers: X-Api-Key: <key>

{
  "session_id": "...",
  "last_seq": 5,
  "results": [
    { "seq": 1, "request_id": "req-123-1", "action": "navigate",
      "success": true, "error": "", "at_utc": "..." },
    { "seq": 2, "request_id": "req-123-2", "action": "ui.click",
      "success": false, "error": "The selected visible action is no longer available." }
  ]
}
Poll with after=<last_seq> for only new results.

=====================================================================
POSTMAN - EXACT REQUESTS TO PASTE
=====================================================================
A) Find the device:
   GET https://localhost:7116/api/ai-bridge/sessions?bed_id=9330
   Header: X-Api-Key: <key>

B) Get the screen controls (the one GET you need):
   GET https://localhost:7116/api/ai-bridge/sessions/{session_id}/options
   Header: X-Api-Key: <key>

C) Trigger the UI (the one POST you need):
   POST https://localhost:7116/api/ai-bridge/sessions/{session_id}/actions
   Headers: X-Api-Key: <key>, Content-Type: application/json
   Body:  { "actions": [ <copy any "action" object from B> ] }

D) (optional) confirm:
   GET https://localhost:7116/api/ai-bridge/sessions/{session_id}/results?after=0
   Header: X-Api-Key: <key>

ERRORS YOU MAY SEE
------------------
401  -> missing/wrong X-Api-Key
503  -> AiBridge:ApiKey not configured in appsettings.json (outside Dev)
404  -> session_id unknown: device has not opened its screen yet
400  -> bad action name / navigate to external URL / empty body
empty options[] -> wait ~2 s after the page loads; the device publishes
                   its screen automatically every ~25 s and on changes
